## 🚀 Featured Project

### 🇳🇵 [Constitution of Nepal: RAG Chatbot](https://github.com/abcsilence/RAG)

An AI chatbot that answers questions about the **Constitution of Nepal** and cites the exact articles it used.

- 🔍 &nbsp;**Hybrid retrieval:** semantic search (FAISS + `bge` embeddings) combined with keyword search (BM25)
- 💬 &nbsp;**Streaming answers** from an LLM served by Groq, grounded only in the constitution text
- 📊 &nbsp;**Evaluation script** to compare embedding models and chunk sizes
- ⚡ &nbsp;**FastAPI** backend with a **React + Vite** chat interface
